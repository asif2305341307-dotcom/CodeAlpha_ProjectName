# Iris Flower Classification

## Project Overview

This project is completed as part of the CodeAlpha Data Science Internship.

The objective of this project is to classify Iris flowers into three species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

using flower measurements.

## Features Used

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Machine Learning Model

Logistic Regression

## Dataset

The dataset contains 150 Iris flower samples.

## Workflow

1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Data Visualization
5. Train-Test Split
6. Feature Scaling
7. Model Training
8. Prediction
9. Model Evaluation
10. Confusion Matrix

## Evaluation

The model was evaluated using:
